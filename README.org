#+TITLE: dotfiles

* How to Install

** Needed programs

 * Git
 * GNU Stow

** Steps

Clone the repository

#+begin_src bash
  $ git clone https://codeberg.org/svngms/dotfiles ~/.dotfiles
#+end_src

use `GNU Stow` to install the config

#+begin_src bash
  $ cd ~/.dotfiles && stow .
#+end_src
