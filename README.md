## How to Install

### Needed programs

 - Git (ofc)
 - GNU Stow

### Steps

Clone the repository

```console
$ git clone https://codeberg.org/svngms/dotfiles ~/.dotfiles
```

use `GNU Stow` to install the config

```console
$ cd ~/.dotfiles && stow .
```
